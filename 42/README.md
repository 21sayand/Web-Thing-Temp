# Sayand | Student Profile & Systems Portfolio (Flask Web Application)

A modern, interactive web application featuring an official **Student Profile System** and portfolio built with **Python & Flask**, showcasing **Sayand**'s academic records, extracurricular activities, and software systems.

---

## 🌟 Key Features

1. **Poetic Hero Section at Top**:
   - Features human-centric bio, headline ("Crafting software with quiet care and human warmth"), quote, core skill tags, and quick action links.

2. **Official Student Profile System**:
   - **Personal Details & Verification**: Name (`Sayand`), Register Number (`stm23cs043`), Degree, Semester (`Semester 7`), DOB (`March 2026`), Address (`Kuthuparamba, Kannur, Kerala`), and Contact.
   - **Demographics & Favorite Companies**: Gender selection via custom radio cards, Blood Group dropdown (`O+`), and Favorite Companies (`Tesla, IBM`).
   - **Academic Performance Table (7 Semesters)**:
     - Verified cumulative average of **CGPA = 7.75**.
     - Semester 4 calibrated to **8.45 SGPA**.
     - Semesters 1, 2, 3, 5, 6, 7 calibrated between **7.12 and 7.89 SGPA**.
     - Fully editable table with dynamic client-side recalculation.
     - 4 clean columns: `Semester`, `Term & Core Coursework`, `SGPA`, and `Cumulative CGPA` (no credits, no status/pass labels).
   - **Technical Skills**: Interactive checkboxes for Python, Java/Android, Web Development, DSA, Flutter/Dart, and SQL Databases.
   - **Extracurricular Activities**:
     - **Cricket** with glowing **fav player** button (interactive Easter egg hover that blurs screen and reveals randomized smiley with `benstokes`).
   - **Live Dynamic Student ID Card Preview**: Single profile portrait on the page with real-time field synchronization.

3. **Systems & Projects (Compact List)**:
   - Clean, lightweight list of core software projects:
     - **The Orbit AI** — Real-time collaborative developer workspace for system architectures.
     - **Vehicle Tracking System** — Android fleet telemetry with low-drain GPS & geofencing.
     - **Digital Security App** — Android DNS-level packet inspection & threat detection.

4. **Visual Aesthetics & Theme**:
   - Modern warm paper design system (`#FAF8F5`, obsidian text, amber accents).
   - Animated ambient liquid caustics background canvas.
   - Fully responsive on mobile, tablet, and widescreen.
